# املاک بام یزد

وب‌سایت راست‌به‌چپ املاک با تم مشکی و طلایی، جستجوی خرید و فروش، رهن و اجاره، رهن کامل، پیش‌فروش و معاوضه.

- ثبت و ویرایش ملک توسط مالک و بررسی آگهی در پنل مدیریت.
- اطلاعات تماس و نشانی مالک فقط برای خود مالک و مدیر قابل دسترسی است.
- سه بنر هرو با نسخه‌های مستقل دسکتاپ و موبایل.
- نمایش نوبتی تماس عرشیا رضایی (09136084068) و حمید طامهری (09121380003).

## فناوری

React، TypeScript، Vinext، Cloudflare Workers، D1 و R2. احراز هویت فعلی از طریق ChatGPT Sites انجام می‌شود؛ OTP پیامکی متصل نیست. اجرای خارج از Sites نیازمند جایگزین‌کردن اتصال احراز هویت و تنظیم منابع Cloudflare است.

## اجرا و بررسی

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node scripts/test-estate.mjs
pnpm dev
pnpm build
```

جداول در `db/schema.ts` و migrationها در `drizzle/` هستند. متغیر محرمانه `ADMIN_SETUP_CODE` فقط در محیط اجرای سرور تنظیم می‌شود و در سورس قرار نمی‌گیرد. اطلاعات کاربران و فایل‌های بارگذاری‌شده جزو این مخزن نیستند.

این انتقال بر اساس سورس منتشرشده Sites با کامیت `ce11c80979ae6929dad7b988d92c34e00775ab6d` انجام شده است.
