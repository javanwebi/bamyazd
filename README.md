# املاک بام یزد

وب‌سایت راست‌به‌چپ املاک با تم مشکی و طلایی، جستجوی خرید و فروش، رهن و اجاره، رهن کامل، پیش‌فروش و معاوضه.

- ثبت و ویرایش ملک توسط مالک و بررسی آگهی در پنل مدیریت.
- اطلاعات تماس و نشانی مالک فقط برای خود مالک و مدیر قابل دسترسی است.
- سه بنر هرو با نسخه‌های مستقل دسکتاپ و موبایل.
- نمایش نوبتی تماس عرشیا رضایی (09136084068) و حمید طامهری (09121380003).

## فناوری

React، TypeScript، Vinext، Cloudflare Workers، D1 و R2. احراز هویت فعلی از طریق ChatGPT Sites انجام می‌شود؛ OTP پیامکی متصل نیست. اجرای خارج از Sites نیازمند جایگزین‌کردن اتصال احراز هویت و تنظیم منابع Cloudflare است.

## اجرا و بررسی

```sh
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit
node scripts/test-estate.mjs
pnpm dev
pnpm build
```

جداول در `db/schema.ts` و migrationها در `drizzle/` هستند. متغیر محرمانه `ADMIN_SETUP_CODE` فقط در محیط اجرای سرور تنظیم می‌شود و در سورس قرار نمی‌گیرد. اطلاعات کاربران و فایل‌های بارگذاری‌شده جزو این مخزن نیستند.

این انتقال بر اساس سورس منتشرشده Sites با کامیت `ce11c80979ae6929dad7b988d92c34e00775ab6d` انجام شده است.

## استقرار مستقل روی Vercel

برای Vercel، دستور `pnpm run build` با `VERCEL=1` از Next.js + Webpack استفاده می‌کند تا خروجی استاندارد `.next/` ایجاد شود. نسخه اصلی Cloudflare/ChatGPT Sites همچنان با Vinext کار می‌کند.

نمایش صفحه، بنرها و فایل‌های عمومی به متغیر محیطی وابسته نیست؛ ولی دریافت آگهی‌های واقعی و فایل‌های مالک نیازمند اتصال ایمن به منابع ذخیره‌سازی اصلی است. متغیرهای زیر را فقط در Environment Variables پروژه Vercel تنظیم کنید، نه در GitHub:

- `BAM_D1_ACCOUNT_ID`: شناسه حساب Cloudflare صاحب دیتابیس
- `BAM_D1_DATABASE_ID`: شناسه دیتابیس D1 موجود با جداول پروژه
- `BAM_D1_API_TOKEN`: توکن محدود به اجرای کوئری روی D1
- `BAM_R2_ACCOUNT_ID` و `BAM_R2_BUCKET`: حساب و Bucket تصاویر موجود
- `BAM_R2_ACCESS_KEY_ID` و `BAM_R2_SECRET_ACCESS_KEY`: کلیدهای محدود S3 API برای همان Bucket
- `ADMIN_SETUP_CODE`: کد فعال‌سازی اولیه مدیریت (محرمانه)

در نبود این تنظیمات، عملیات داده‌ای با خطای کنترل‌شده متوقف می‌شوند. هیچ Migration، حذف دیتابیس یا انتقال خودکار داده‌ای در Build انجام نمی‌شود. D1 REST تحت محدودیت‌های API مدیریتی Cloudflare است و برای ترافیک بالا باید به Worker محدودشده تبدیل شود.

**نکته امنیتی مهم:** هدرهای هویت ChatGPT Sites در Vercel قابل جعل هستند. نسخه مستقل Vercel تا اتصال ارائه‌دهنده احراز هویت امن و نشست امضاشده، ثبت ملک و مدیریت را مسدود می‌کند؛ ورود قدیمی در ChatGPT Sites تغییر نمی‌کند.

برای تست محلی ساخت Vercel: `VERCEL=1 pnpm run build`
